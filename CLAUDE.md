# WV T1D Adults Website

Static HTML site for WV T1D Adults, a nonprofit for adults with type 1 diabetes in West Virginia. Live at https://wvt1dadults.org, hosted on Netlify, no backend/build system.

For anything beyond a quick fact, read the docs below rather than guessing:

- **[`docs/PROJECT_SUMMARY.md`](docs/PROJECT_SUMMARY.md)** — full technical reference: file structure, page-by-page breakdown, design system, and the photo gallery's Google Drive integration (read this before touching `gallery.html` or `gallery-drive.js`)
- **[`docs/TODO.md`](docs/TODO.md)** — current to-do list, what's done, what's in progress, and known gotchas

Deploys happen by dragging the updated folder into the Netlify dashboard — there's no CI/CD.
